# City Surfers (Unity)

An endless-runner style game built in Unity 2021.3 LTS (C#) by a three-person team: procedural map spawning, obstacle sets, collectibles, a leaderboard and saved player data.

## Team

- Erdem Süren ([@erdestre](https://github.com/erdestre))
- [@tukelayberk](https://github.com/tukelayberk)
- [@Katsumoto-15](https://github.com/Katsumoto-15)

## Run

Open the folder with Unity 2021.3 LTS (Unity Hub → Add project) and press Play in the main scene.

This repository is archived as a record of earlier game-development work.
